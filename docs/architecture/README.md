## Convenciones de estado

- **Decidido para implementar:** decisión técnica aprobada por la instrucción integral actual y registrada en ADR.
- **Objetivo verificable:** umbral que debe comprobarse antes de declarar un incremento listo; no es un resultado ya obtenido.
- **Diseñado, no ejecutado:** contrato, modelo o procedimiento sin aplicación implementada.
- **Pendiente de autorización:** acción con coste, publicación, datos reales, acceso externo o instalación.
