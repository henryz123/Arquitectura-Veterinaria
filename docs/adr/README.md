# ADR — Arquitectura - Veterinaria

Estos ADR registran decisiones técnicas para G4; no prueban una implementación. El dueño de ejecución debe reabrir un ADR si una dependencia disponible o una restricción V1 lo contradice. Cada cambio de ADR se realiza en un commit separado del cambio de aplicación que lo consume.

| ADR | Decisión | Estado |
|---|---|---|
| 0001 | monolito modular y límites de ownership | aceptado para G4 |
| 0002 | contexto de tenant y defensa en profundidad | aceptado para G4 |
| 0003 | cuentas separadas y sesión opaca | aceptado para G4 |
| 0004 | PostgreSQL, Flyway, integridad y concurrencia | aceptado para G4 |
| 0005 | REST/OpenAPI, errores e idempotencia | aceptado para G4 |
| 0006 | eventos internos, auditoría y notificaciones | aceptado para G4 |
| 0007 | datos sintéticos, privacidad y recuperación | aceptado para G4 |
| 0008 | ejecución local, CI y demo S/ 0 | aceptado como diseño; despliegue pendiente de autorización |
