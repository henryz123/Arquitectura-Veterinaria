# G4-I01 - runbook local para la presentacion del 24 de octubre de 2026

## Limite de este runbook

Este procedimiento inicia solamente el vertical local ya implementado. No ejecuta Flyway,
no corre `scripts/invoke-authorized-flyway-v012.cmd`, no crea datos, no aplica V013 y no publica.
Todos los recorridos usan datos sinteticos configurados solo en `.env.local`, archivo ignorado por Git.

Se necesitan dos ventanas de PowerShell: una para Spring Boot y otra para Angular.
Una tercera es opcional para las comprobaciones HTTP.

## 1. Comprobacion de PostgreSQL

Use una consola temporal en la raiz. Este comando solo lee la base exclusiva y elimina
la contrasena de la sesion al terminar.

```powershell
$dotenv = @{}
Get-Content .env.local | ForEach-Object {
  if ($_ -match '^\s*([A-Za-z_][A-Za-z0-9_]*)=(.*)$') {
    $value = $matches[2].Trim()
    if (($value.StartsWith('"') -and $value.EndsWith('"')) -or ($value.StartsWith("'") -and $value.EndsWith("'"))) {
      $value = $value.Substring(1, $value.Length - 2)
    }
    $dotenv[$matches[1]] = $value
  }
}
$env:PGPASSWORD = $dotenv['AV_MIGRATION_DB_PASSWORD']
$env:PGOPTIONS = '-c default_transaction_read_only=on'
& 'C:\Program Files\PostgreSQL\18\bin\psql.exe' -X -v ON_ERROR_STOP=1 -h localhost -U $dotenv['AV_MIGRATION_DB_USER'] -d arquitectura_veterinaria -Atc "select current_database(), current_setting('server_version'), current_user; select count(*) from flyway_schema_history where success and version between '001' and '012';"
Remove-Item Env:PGPASSWORD -ErrorAction SilentlyContinue
Remove-Item Env:PGOPTIONS -ErrorAction SilentlyContinue
```

Resultado esperado: `arquitectura_veterinaria|18.6|av_schema_owner` y luego `12`.
Si el servicio no responde, compruebe `Get-Service postgresql-x64-18`. Solo si aparece
detenido, abra PowerShell como administrador y ejecute `Start-Service -Name postgresql-x64-18`.

## 2. Terminal 1 - backend Spring Boot

Desde la raiz, cargue las variables locales sin imprimirlas, fuerce Flyway a `false`
y deje esta consola abierta:

```powershell
$dotenv = @{}
Get-Content .env.local | ForEach-Object {
  if ($_ -match '^\s*([A-Za-z_][A-Za-z0-9_]*)=(.*)$') {
    $value = $matches[2].Trim()
    if (($value.StartsWith('"') -and $value.EndsWith('"')) -or ($value.StartsWith("'") -and $value.EndsWith("'"))) {
      $value = $value.Substring(1, $value.Length - 2)
    }
    $dotenv[$matches[1]] = $value
  }
}
foreach ($key in @('AV_DB_URL','AV_DB_USER','AV_DB_PASSWORD','AV_MIGRATION_DB_USER','AV_MIGRATION_DB_PASSWORD')) {
  if (-not $dotenv[$key]) { throw "Falta la variable local requerida: $key" }
  Set-Item -Path "Env:$key" -Value $dotenv[$key]
}
$env:AV_FLYWAY_ENABLED = 'false'
$env:JAVA_HOME = 'C:\Users\HNR05\.jdks\ms-21.0.12.1'
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
Set-Location 'C:\Users\HNR05\Documents\Arquitectura-Veterinaria\backend'

```


Resultado esperado: HTTP `200`.

## 4. URL y recorridos autorizados

- URL: `http://127.0.0.1:4200/login/veterinaria-aurora`.
- Aurora STAFF: correo sintetico `administracion@demo.invalid`; escriba la contrasena
  que corresponde a `AV_DEMO_AURORA_PASSWORD` sin mostrarla.
- Bosque STAFF: mismo correo sintetico; escriba la contrasena de
  `AV_DEMO_BOSQUE_PASSWORD` sin mostrarla.
- SaaS usa `AV_DEMO_SAAS_EMAIL` y `AV_DEMO_SAAS_PASSWORD`; su verificacion actual es
  E2E/API, no una pantalla adicional para la demostracion.

Mostrar solamente login, perfil protegido de Aurora, logout, redireccion al login y perfil
protegido de Bosque. No mostrar recuperacion administrativa ni B02--B06. El reemplazo de roles
esta verificado por pruebas de integracion, pero esta interfaz aun no contiene una pantalla para ejecutarlo.

## 5. Si algo no inicia y cierre seguro

- Si Spring Boot falla, conserve su salida de consola, confirme JDK 21 con `java -version`,
  que `.env.local` exista e inicie de nuevo solo despues de verificar PostgreSQL. No ejecute Flyway como remedio.
- Si Angular falla, permanezca en `frontend`, ejecute de nuevo el mismo comando y compruebe que 4200 no este ocupado con
  `Get-NetTCPConnection -LocalPort 4200 -State Listen -ErrorAction SilentlyContinue`.
- Si 8080 o 4200 estan ocupados, identifique el PID y no finalice procesos ajenos durante la presentacion.
- Para cerrar, pulse `Ctrl+C` una vez en cada consola de Spring Boot y Angular. PostgreSQL es
  un servicio local y no debe detenerse para este cierre.

Tras terminar la presentacion, deje backend y frontend detenidos. La base se mantiene sin
migraciones automaticas y G4-I01 permanece congelado.
